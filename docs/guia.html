🎬 Editor de torrents · Guía visual

Pipeline en GitHub Actions contra tu tabla public.torrents de Supabase: limpieza + IDs (TMDB · IMDb · AniList · Kitsu · MAL) + español + reordenador de id.

#EtapaQué hace
1Limpieza basuraBorra readme / sample / trailer…

3absolute_episodeBorra episodio solo en absolute_episode
4IDs por nombreResuelve tmdb/imdb/anilist/kitsu/mal
5Reintentos NULLtitle_text + variantes + IMDb/TVmaze
6Español + dedupeMáx 3, mín 2 en español (audio → subtítulos)
7ReordenadorDeja id en 1..N sin huecos
